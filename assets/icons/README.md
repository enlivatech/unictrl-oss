# Unictrl icons

The Unictrl icons, licensed under the GPL v3.0 like the rest of the repository; forks may use them.
`svg/` holds the vector versions to edit.

| File | Use |
| --- | --- |
| `mac/Unictrl.icns` | App icon on macOS 15–25 (`CFBundleIconFile = Unictrl`) |
| `mac/Unictrl.icon` | Layered icon for macOS 26 and later, compiled by `macos/build-app.sh` |
| `mac/menubar/UnictrlMenubarTemplate(@2x).png` | Menu bar, 18 pt template image (`isTemplate = true`) |
| `windows/Unictrl.ico` | exe, window and taskbar (16–256, full-bleed as Windows icons are) |
| `windows/tray/UnictrlTray.ico` | Notification area |
| `windows/png/` | Single sizes up to 1024 |
| `svg/` | Vector versions |
